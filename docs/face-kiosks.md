# راه‌اندازی خودکار کیوسک‌های ورود با چهره

دیگر نیازی نیست برای هر دستگاه URL جداگانه‌ای با `deviceId` بسازید. برنامه IP دستگاه درخواست‌دهنده را با ستون `Ip` جدول `[FoodReservation_API].[dbo].[Devices]` تطبیق می‌دهد و `KioskId` همان ردیف را برای اتصال به سرویس چهره استفاده می‌کند.

برای نمونه، اگر IP کیوسک ساروناز `10.128.141.140` و IP کیوسک مطهری `10.128.149.12` در ردیف‌های دستگاه ثبت شده باشد، هر دو می‌توانند همان آدرس عادی سامانه را باز کنند. برای هر درخواست، ردیف با IP همان مرورگر پیدا می‌شود و KioskId از بانک خوانده می‌شود. بعد از تغییر KioskId در جدول، با تازه‌سازی صفحه مقدار جدید اعمال می‌شود.

در `appsettings.json` فقط رشته اتصال `ConnectionStrings:KioskRegistry` را وارد کنید. حساب SQL باید اجازه خواندن جدول `dbo.Devices` را داشته باشد. برای امنیت بهتر، رشته اتصال را در متغیر محیطی IIS با نام `ConnectionStrings__KioskRegistry` قرار دهید و در فایل مخزن خالی بگذارید.

این روش وقتی IP درخواست وب به IP ثبت‌شدهٔ کیوسک برسد کار می‌کند. اگر IIS پشت پراکسی یا NAT است و همه درخواست‌ها را با یک IP می‌بیند، تطبیق یکتا ممکن نیست؛ در این حالت IP واقعی کلاینت باید با تنظیم معتبر Forwarded Headers به برنامه برسد یا آدرس شبکه‌ای دستگاه‌ها اصلاح شود. اگر IP ثبت نشده یا تکراری باشد، سامانه اتصال را متوقف می‌کند تا شناسه اشتباه به دستگاه دیگری ندهد.
